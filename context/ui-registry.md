# UI Registry

Living document — read before building any new component. Match existing patterns exactly before inventing new ones.

## How to Use

1. Check the registry for a similar component → copy its exact classes/patterns.
2. Not found → build per `ui-rules.md` (component specs) + `ui-tokens.md` (raw token values), then add an entry (file, date, classes, notes).
3. Update after every component is built.

## Cross-Cutting Patterns (know these first)

- **Modal/sheet shell** — overlay `fixed inset-0 z-50 bg-overlay-alpha`; desktop centered modal keeps Framer `dialogOverlay`/`dialogContent`; mobile sheets use **`CssBottomSheet`** (React/CSS, no Framer). Canonical rules (2026-09-07 final):
  - Slide-up/down via inline `translate3d` + **450ms** `ease-[cubic-bezier(0.22,1,0.36,1)]`, `transform-gpu`, `motion-reduce:transition-none`, `fixed inset-x-0 bottom-0 z-50`, `rounded-t-2xl` bodies cap at **`max-h-[85dvh]`** (dvh — Chrome Android vh includes the hidden URL bar). Keeps itself mounted for exit; post-paint effect (deps `[mounted]`) flips `entered` so the transition always slides from a painted frame (a single rAF flip was racy).
  - **Drag (native Pointer Events):** whole sheet subtree `touch-none overscroll-y-contain select-none cursor-grab`; a per-mount effect sets `touch-action: none` on EVERY descendant (touch-action is NOT inherited; Chrome fires `pointercancel` over auto-touch-action elements → the old "moved slightly then snapped back" bug). Travel > 8px engages drag; explicit `setPointerCapture` only for `pointerType !== "touch"` (touch uses implicit capture). Content scrolls via JS handoff to the first `overflow-y:auto/scroll` ancestor while sheet offset is 0.
  - **Sheet grabs a down-drag ONLY at content-top (`scrollTop <= 0`).** At content-bottom, continued scroll-down gestures rubber-band the scrollable's first content child upward with `bottomNudge()` and spring it back on release; this also works when the sheet content fits (`scrollHeight === clientHeight`) by treating the `overflow-y-auto` body as the scroll target. It does **not** grab the sheet or steal scroll-back-up. Close on long forms = top-band fling or close button.
  - **Release (`resolveReleaseTarget` in `lib/bottom-sheet-drag.ts`, called from `settleDrag`):** fling down > **0.8px/ms** OR slow release at/past **50% of sheet height** → dismiss (`onClose`); fling up < −0.8px/ms → top snap; slow release before the line → **springs back with overshoot** (`ease-[cubic-bezier(0.34,1.56,0.64,1)]`) to the snap the gesture STARTED from (`startSnapRef` at pointerdown). **Dismiss guard:** a `dismiss` is honored only past `MIN_SHEET_DRAG = 4px` — a pure-scroll gesture snaps back to TOP, never closes. `settleDrag` re-entry guard `activePointer.current === null` (pointerup + eventless `lostpointercapture`). Elastic top edge via `elasticOffset` (asymptote −24px) on raw live-drag distance; settles only write non-negative targets. Momentum glide for content flings (`startMomentum`: engages > 0.35px/ms, τ 250ms, stops < 0.03). Top-band pull `topPull(delta)`: `48·(δ/48)^1.25` over `TOP_PULL_BAND = 48px`, then 1:1 (seam continuous at 48). Live drag motion writes `translate3d(0, y, 0)` directly on the DOM (`setSheetOffset` → imperative `style.transform` + `offsetRef`) so the sheet tracks the finger without one-event React lag; transition is disabled inline during drag and restored on settle. **Settle/close are React-state-driven**: `sheetTranslate` state (`number | null`, null = first-frame off-screen `translate3d(0,100%,0)`) renders the transform; `animateSheetTo` syncs state to `offsetRef` **before** any parent re-render (`setSheetTranslate(from)` then rAF `setSheetTranslate(target)`) so a stale 0 can never yank a dragged sheet back to top; entrance = mount at 100% → post-paint effect commits `sheetTranslate(0)` (deterministic slide, single-rAF batching was the original "pop-in" bug), exit/springs = `animateSheetTo` with a `SHEET_MS = 450ms` timeout driving `onDone`. Dismiss additionally syncs `setSheetTranslate(offsetRef.current)` before `onClose?.()` — the parent's open=false re-render must commit the finger's offset, not sheetTranslate's rest value.
  - Snap positions derive from measured sheet height; **no dots rail** (removed 2026-09-07 — MID reachable only by manual slow-drag settle). Drag handle `h-1 w-10 rounded-full bg-border-strong` stays in consumer bodies. Used by NewEventModal, LogEntryModal, IncreaseBudgetModal, ArchiveEventModal, VoidEntryModal, ReceiptReview, EntryDetailModal, admin DepartmentsListClient (`hideAt="md"`). `sheetSlideUp` removed from `lib/motion-variants.ts` — do not reintroduce Framer for mobile sheets. [Superseded chain: framer native → `use-drag-to-dismiss` v1–v4 → native inline → 3-snap port → elastic top → momentum → final. Full iteration history + user reports: `context/progress-tracker.md` 2026-09-07 entry.]
- **`scrollbar-hide`** — plain CSS class in `app/globals.css` (`scrollbar-width: none` + `::-webkit-scrollbar { display: none }`). An `@utility` version did NOT compile under Turbopack.
- **Entry animation** — shared `lib/motion-variants.ts`: `staggerContainer` + `fadeUpItem` (fixed tween, `y: 10`, `0.28s`, ease `[0.16,1,0.3,1]`, 40ms stagger / 30ms first delay). GSAP migrated out 2026-07-18. Landing/hero uses `AnimatedBlock`; interactive entrances (post-2026-09-07) use `components/ui/FadeIn.tsx`.
- **FadeIn** (`components/ui/FadeIn.tsx`) — `useFadeIn(delayMs)` hook co-located; `opacity 0→1`, `translateY(16px)→0`, `0.7s ease-[cubic-bezier(0.22,1,0.36,1)]`; reduced-motion guard (`matchMedia`) returns `{}`; SSR-safe. **Once visible the style uses `transform: "none"` (NOT `translateY(0)`) — a lingering identity transform becomes a fixed-position containing block and traps `position: fixed` dialogs (commit `fde204e`).** Per-item stagger `delay={30 + index * 80}`. Supersedes `EventPageEntrance.tsx` (deleted). **Performance exception (2026-09-07):** `TreasurerHomeClient` first-paint content deliberately does not use FadeIn; server-rendered event cards must be visible immediately. Keep FadeIn for non-critical/interactions-only motion.
- **Receipt images** — `image_url` stores the storage **key**, never a browser URL; render via `GET /api/entries/{id}/image` (session-authed proxy; `?i=N` pages multi-image), with `onError` → styled placeholder.
- **Tokens only** — `@theme` tokens via generated utilities (`bg-surface`, `text-text-primary`, `border-border`); no hex, no raw Tailwind color classes. Poppins via `font-sans`.
- **Immersive pages** — event/report/notifications detail hide top bar + bottom nav (`lib/event-route.ts` `isImmersivePage`).
